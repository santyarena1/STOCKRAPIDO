# Sincronizador StockRápido

Extensión local para sincronizar Tokin usando la sesión y la conexión residencial del navegador.

## Cargar sin publicar

1. Abrí `chrome://extensions` en Chrome o `edge://extensions` en Edge.
2. Activá **Modo desarrollador**.
3. Elegí **Cargar descomprimida**.
4. Seleccioná la carpeta `stockrapido-extension/` completa.
5. Fijá **Sincronizador StockRápido** en la barra del navegador.

## Usar

1. Iniciá sesión normalmente en `https://tokintienda.com.ar/`.
2. Abrí la extensión e ingresá el email y contraseña de StockRápido.
3. Presioná **Sincronizar Tokin ahora**.
4. Dejá abierta la pestaña que la extensión enfoca mientras recorre catálogo, cuenta y pedidos.
5. Seguí el progreso desde el popup. Al finalizar verás cantidades de productos, facturas y pedidos.

La extensión guarda localmente solamente el access token de StockRápido. No lee ni guarda la contraseña de Tokin.
